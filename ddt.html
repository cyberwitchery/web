ddt

codebase evidence for technical due diligence.

ddt collects and structures the evidence behind a software assessment: code health, architecture, dependencies, repository history, ownership, and delivery risk.

analysis that fits the stack

each assessment uses the analyzers relevant to the technologies present: languages, frameworks, dependencies, repository history, build systems, and delivery infrastructure.

languages frameworks dependencies repository history build systems delivery infrastructure

analyzers share one evidence model and can be added independently. support for a new technology extends the system without changing how evidence is collected, sealed, reviewed, or compared.
